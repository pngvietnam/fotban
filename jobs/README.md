Milestone 13 job definitions/order live in `types/scheduler.ts`; `services/scheduler.ts` runs them through the existing-service handlers in `lib/scheduler-runtime.ts`. `scripts/run-scheduler.ts` is the shared local/cron/hosted one-shot entrypoint. PostgreSQL session locking and JobRun persistence keep execution independent of the web/dev process. No OS task or daemon is automatically installed. See `docs/SCHEDULER.md` for activation, recovery and deployment.
